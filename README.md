# StudySched

StudySched is a React-based study scheduling application designed to help students efficiently manage assignments and track their workload. The app was inspired by observing peers struggle to balance multiple school tasks and aims to make planning and time management easier.

# Features
Interactive Assignment Management: Add, edit, and allocate assignments to specific days with a responsive, user-friendly interface.
Daily Workload Indicators: Visual alerts for high workload days to help students balance their study time.
Real-Time Sync: Firebase integration allows authentication and real-time updates, keeping schedules consistent across devices.

# Technologies
Frontend: React, JavaScript, Tailwind CSS
Backend: Firebase (Authentication & Realtime Database)
